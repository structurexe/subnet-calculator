# Subnet Calculator

Enter an IPv4 address with a CIDR prefix (e.g. `192.168.10.77/26`) and get the network, broadcast, subnet mask, wildcard, first/last host and the number of usable hosts. Built with plain HTML, CSS and JavaScript using only bitwise operations, no libraries.

**Run it:** open `index.html` in a browser.

**Files:** `index.html` (page), `style.css` (look), `script.js` (the `subnet()` function and UI).

---

# Калькулятор подсетей

Введите IPv4-адрес с префиксом CIDR (например, `192.168.10.77/26`) и получите сеть, broadcast, маску, wildcard, первый и последний хост и число доступных хостов. Чистые HTML, CSS и JavaScript, только побитовые операции, без библиотек.

**Запуск:** откройте `index.html` в браузере.
